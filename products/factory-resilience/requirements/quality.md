# 重現與品質

驗證案例參照 [scenarios.yaml](../data/scenarios.yaml) 及[共同評測](../../../docs/model-challenge-evaluation.md)。

### REQ-FQ-01 保存與重播保持業務狀態

保存內容須完整保留場景版本、訂單、排程、當前時間、工序狀態、材料去向與已生效回報。載入不合法或不相容保存內容時，說明問題並保留現有工作。播放速度只改變觀看節奏。
- 里程碑：M2
- 優先：必要

#### AC-FQ-01 保存後繼續與直接執行一致
- Given `replay_cases` 的保存點與播放設定
- When 分別直接執行及保存、重新載入後繼續至終點
- Then 工序、材料、事件生效次數與所有指標完全相同；同一場景反覆執行仍相同
- 驗證：自動

#### AC-FQ-02 不合法保存的保護
- Given `invalid_saved_states` 中包含負庫存或未知場景版本的內容
- When 嘗試載入
- Then 明示拒絕理由，原場景時間、訂單、材料與排程均不變
- 驗證：自動

### REQ-FQ-02 可辨識與可操作

在資料指定畫面尺寸中，主要任務可由可辨識控制完成；狀態不僅靠顏色區分。鍵盤可操作場景選取、執行、暫停、逐事件、重設與結果檢視；不得讓立體鏡頭遮掉必要資訊。
- 里程碑：M2
- 優先：必要

#### AC-FQ-03 可讀的工廠與時間表
- Given `presentation_review` 的畫面尺寸與必要欄位
- When 依序以鍵盤完成核心路徑並檢視等待、加工、故障與交付狀態
- Then 各必要欄位可讀、控制可聚焦操作、狀態有文字標籤，owner 可辨認等待原因與故障位置；結果依共同評測附畫面與操作證據
- 驗證：人工確認
