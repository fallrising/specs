# 法術與反應規則

節點、數值與案例全部引用 [scenarios.yaml](../data/scenarios.yaml)。同名元素對應 `catalog` 與 `elements`，不能新增未列出的隱含反應。

### REQ-SPR-01 合法術式與成本預扣

每個發射段必須是「投射物、元素、可選修飾、可選命中觸發」；元素擇一，分裂、追蹤及延遲在同段各不得重複，修飾可交換順序但結果相同。命中觸發只能位於段尾且必須接完整子段。不得循環、合流、共用節點、留懸空連線或超出 `composition` 的節點數、段數與成本。錯誤依 `composition.error_priority` 顯示。

每段費用為該段節點單價總和，乘上該段最壞發射數；最壞發射數是前段的最壞發射數乘本段的分裂倍數，根段以前置單次觸發計。全術式費用是所有段的費用相加，包含預付命中子段。接受施法即一次扣款，未命中或後續被抑制不退費。非法術式、冷卻未完或法力不足不發射也不扣款。每輪法力固定，不被動回復。

- 里程碑：M1
- 優先：必要

#### AC-SPR-01 合法術式的成本

- When 預覽並施放，另讓指定投射物未命中
- Then 節點數、各段最壞發射數、總費用與剩餘法力等於各案例預期；未命中不退款，命中子段不再次扣款
- 驗證：自動

#### AC-SPR-02 非法與資源不足拒絕
- Given `recipes.invalid` 以及 `cases.resources` 的不足法力與冷卻情境
- When 嘗試施放
- Then 依資料優先序顯示指定原因，法力、目標與在場投射物不變；不存在只執行合法片段的部分施法
- 驗證：自動

### REQ-SPR-02 可預測的飛行修飾

分裂在段發射時依 `projectile.split_angles_degrees` 同時產生投射物，保留各自元素全額效果，不分攤傷害；角度的正負方向、投射物序與瞄準方向何時固定依 `projectile` 的 `split_angle_convention`、`projectile_order`、`aim`。延遲在該段觸發後等待選定的允許時間，再發射；等待不消耗投射物存活時間。追蹤在實際發射時選取範圍內最近活目標，同距依目標 ID；鎖定目標死亡後沿當時方向飛行，不重新選敵。無追蹤時沿瞄準方向直行。

投射物只能直接命中首個相交的活目標，同時相交依行進距離再依 ID 決定，命中即消失；相交以每個事件步內走過的整段路徑判定，命中時刻記為該事件步的結束時刻（`projectile.hit_detection`）。到達存活或距離上限而未命中則消失且不觸發子段。命中子段從該輪固定施法位置重新發射，瞄準原命中目標在觸發當刻的位置；若該目標已死亡就抑制並記錄原因。子段的延遲與追蹤仍按相同規則處理。

- 里程碑：M1
- 優先：必要

### REQ-SPR-03 元素優先序與狀態

火：先解除冰凍；目標若濕潤則消耗濕潤、套用濕潤減傷且不燃燒，否則直接傷害並新增或刷新燃燒。水：不直接傷害，先熄滅目標燃燒再套用濕潤；既有冰凍保留。冰：先熄滅燃燒，造成直接傷害；濕潤者消耗濕潤後冰凍，乾燥且未冰凍者緩速，已冰凍者刷新冰凍。冰凍取代緩速，禁止移動；緩速不與冰凍疊加。

電：乾燥目標使用基礎傷害；濕潤目標使用增幅傷害並消耗其濕潤，再依距離與 ID 選取導電半徑內（含邊界）仍濕潤的鄰近活目標導電。導電傷害同樣消耗濕潤，但不再傳導、不觸發命中子段，也不改變燃燒或冰凍。生命值最低為資料中的死亡值，死亡立即移除可命中資格、清除狀態並取消該目標後續持續傷害。

重複同種狀態只刷新期限不疊加強度。燃燒刷新時重新安排後續週期。相同時刻先完成到期持續傷害，再移除到期狀態，之後依施法接受順序、段序、投射物序及目標 ID 處理直接命中；每次直接命中的狀態反應與導電處理完才排其子段。子段最早在下一個事件步發射。事件順序與全部數值以 `event_order`、`elements` 為準。

- 里程碑：M1
- 優先：必要

### REQ-SPR-04 有界連鎖

每次施法連同所有子段共用 `budgets` 的發射與次級傳播預算。投射物實際發射才扣發射額度；導電命中或油格點燃各消耗次級傳播額度。依目前的節點數、段數與成本上限，合法術式最多發射 7 個投射物，發射額度不會用盡，本版只驗證其剩餘值（`budgets.emission_budget_reachability`）。預算不足時依既定事件順序保留已接受事件，抑制後續事件並標示原因，不回溯傷害或退款。持續傷害的週期數受狀態期限限制；它們不能再觸發子段。重置必須取消全部等待發射與持續事件。

- 里程碑：M1
- 優先：必要

#### AC-SPR-06 傳播上限與完整因果
- Given `cases.chain_budget` 的合法術式及濕潤目標群
- When 依案例順序命中，繼續觀察到全部效果結束
- Then 直接與次級命中、剩餘預算、受抑制的目標及理由全部等於預期，遊戲仍可接受重置，沒有額外傳播或無限等待
- 驗證：自動

### REQ-SPR-05 油的可燃鋪展與舊術式相容

M3 新增 `catalog.extension` 的油元素。油格與試驗場座標的對應依 `oil.cell_mapping`；命中點在油格範圍外時不放置油並記錄原因。油不直接傷害，只在命中格放置油並依 `oil` 指定的鄰格順序與間隔鋪展；每次施法的鋪展額度有限，重複占用未點燃油格只刷新期限且仍消耗鋪展名額。超出場地的候選格跳過，不能反覆尋找或繞回起點。油或火再次作用於已燃燒油格時，不刷新地面燃燒期限或重排點燃；火仍依基礎元素規則作用於目標。

火命中非濕潤目標所在油格時點燃該格，再以座標排序走訪相連油格，受原施法的次級預算限制；已燃燒或已走訪格不得再次消耗或生效。濕潤目標的火被抑制時不點燃所在油格。燃油停止鋪展，按固定週期傷害站在該格的活目標；目標燃燒與油地面傷害可同時發生，各自留因果。燃盡移除油。水命中格會移除該格油與地面火並熄滅目標；不移除鄰格。冰不改變油，電不點燃油。油與上述明示規則以外的反應均不發生。

- 里程碑：M3
- 優先：必要
