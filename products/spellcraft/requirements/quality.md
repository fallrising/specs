# 品質與回歸

數值與條件引用 [scenarios.yaml](../data/scenarios.yaml)，共通證據要求見 [共同評測](../../../docs/model-challenge-evaluation.md)。所有 AC 仍是待參考驗證的預期。

### REQ-SPQ-01 可重播與固定規則回歸

每次試驗保留內容版本、起始條件、已接受施法順序、術式與選取參數，供唯讀重播。相同內容與輸入順序必須得到相同法力、生命值、狀態、導電選取、子段與抑制理由；重播不修改儲存術式或原試驗結果。全部合法及非法範例皆屬回歸範圍，不能只展示成功畫面。

- 里程碑：M2
- 優先：必要

#### AC-SPQ-01 重播得到相同因果
- Given `replay.canonical_cases` 的內容、起始條件與施法序列
- When 依 `replay.repeat_count` 重播並比對每個檢查點
- Then 法力、目標、生命值、狀態與事件順序完全等於案例預期，原試驗與儲存術式不變；差異不能以粒子外觀解釋
- 驗證：自動

#### AC-SPQ-02 合法與非法全案回歸
- Given `replay.regression_sets` 的合法術式、非法術式與邊界案例
- When 完整執行全部案例
- Then 每案均附符合或不符合其預期的結果；任何成本、錯誤優先序、狀態或預算差異都列為失敗，不能略過非法輸入
- 驗證：自動

### REQ-SPQ-02 視覺辨識與效能條件

編輯節點、連線方向、可試射狀態、元素效果、生命狀態、事件選取與錯誤原因必須按 `visual_checks` 可辨識，關閉色彩提示仍可完成必要操作。效能只在 `verification_profile` 的設備、作業系統、瀏覽器完整版本、解析度、像素比、畫質、電源模式與固定施法負載鎖定後判斷；不能以空場或關閉必要效果代替。未量測不能填入實測值。

- 里程碑：M2
- 優先：必要

#### AC-SPQ-03 美術與因果可讀
- Given 待批准的畫面參考與 `visual_checks` 指定的元素、反應及密集事件場景
- When owner 分別查看正常與關閉色彩提示的畫面，並操作編輯器與事件選取
- Then 每項檢核均有判定；節點與連線無遮擋、飛行方向可見、元素可辨、文字不裁切、被選事件與來源及目標一致，全部通過才可接受
- 驗證：人工確認

#### AC-SPQ-04 固定負載效能
- Given `verification_profile` 所有必填欄已鎖定且使用指定術式負載與試驗場
- When 依資料暖機並重複測量
- Then 載入、互動延遲與畫面時間百分位全部符合門檻，附設備、版本、解析度、術式與原始紀錄；條件未鎖定或沒有實測即標示未通過評估
- 驗證：手動
