# 數值與可讀品質

數值與容差見 [scenarios.yaml](../data/scenarios.yaml)，模型比較與證據格式見[共同評測](../../../docs/model-challenge-evaluation.md)。

### REQ-OQ-01 可觀察誤差、收斂與保守量

品質報告分開呈現位置、速度、能量及適用的比角動量誤差。以 `convergence_audit` 的逐步收緊時間解析度重跑相同場景，結果須向一致值靠近；解析度是驗證情境輸入，計算方法由實作決定。能量檢查避開推進瞬間，推進前後各自對應新的基準能量。
- 里程碑：M2
- 優先：必要

#### AC-OQ-01 可解析與數值參考的收斂
- Given `convergence_audit` 的場景、解析度、取樣與差異門檻
- When 逐級收緊解析度重跑
- Then 最細結果符合各場景參考誤差，細與更細之差不高於粗與細之差或捨入底限，且低於最大差異；每項誤差獨立報告
- 驗證：自動

#### AC-OQ-02 長時間能量與角動量
- Given `conservation_audit` 的圓軌道長時間案例及受限飛越
- When 無推進地執行並在指定時點取樣
- Then 各時點的最大相對能量誤差符合門檻，圓軌道的比角動量誤差亦符合；不對固定雙中心誤用中央角動量守恆
- 驗證：自動

### REQ-OQ-02 視覺、單位與操作可讀

立體視覺須揭示實際物理平面與方向；數值欄位清楚標示無因次單位，預測與實際、目標與碰撞半徑不僅靠顏色區分。核心操作可由鍵盤完成，鏡頭不應遮掉任務關鍵資訊。
- 里程碑：M2
- 優先：必要

#### AC-OQ-03 可讀且不誤導的任務畫面
- Given `presentation_review` 的畫面尺寸、必要資訊與核心操作
- When 用鍵盤完成操作並轉動鏡頭，分別查看圓軌道與受限飛越
- Then 必要資訊可讀且控制可聚焦，物理平面、有效半徑與來源固定的假設明示；鏡頭改變不影響數值，owner 能區分預測、實際與事件位置
- 驗證：人工確認
