# 物理與任務規則

所有數值、單位、容差與案例以 [scenarios.yaml](../data/scenarios.yaml) 為唯一來源。以下 AC 尚待參考實作確認。

### REQ-OR-01 明列單位與可解析運動

產品採資料定義的平面、固定重力源、探測器無反作用模型，所有物理量須使用對應無因次單位。單一來源基準須能與圓軌道解析位置、速度、能量及比角動量比較。
- 里程碑：M1
- 優先：必要

#### AC-OR-01 圓軌道解析基準
- Given `circular_baseline` 的完整初始條件，沒有推進或任務終止區域
- When 執行至 `reference_samples` 的各時間
- Then 位置與速度分別符合 `tolerances.circular`，初始能量與比角動量符合參考，平面外位置與速度保持為零，數值標示正確單位
- 驗證：自動

### REQ-OR-02 一次推進與燃料帳

推進採瞬時速度變化，按資料定義的理想質量比計算燃料；位置與模擬時間不跳動。輸入與剩餘燃料檢查必須先於生效；一次成功推進後不可再執行另一筆推進，相同識別的重送不能再次扣燃料。
- 里程碑：M1
- 優先：必要

#### AC-OR-02 合法推進與橢圓軌道
- Given `single_impulse_calibration` 的初始質量、速度與推進
- When 執行一次推進並在無任務終止模式飛行至參考遠拱點
- Then 推進後位置、時間、速度、燃料、能量與遠拱點位置速度符合該案例及容差；相同推進重送不產生第二次效果
- 驗證：自動

#### AC-OR-03 拒絕不合法推進
- Given `invalid_impulses` 的燃料不足、無效向量、非有限輸入及第二次推進
- When 嘗試確認各案例
- Then 明示原因，位置、速度、時間、燃料與推進次數保持原值，不自動截短推進量
- 驗證：自動

### REQ-OR-03 有明確終止條件的任務

任務目標是進入指定區域並滿足速度及推進條件；撞擊、越界與逾時是明確失敗原因。顯示最早事件時間與原因，結束後不繼續扣燃料或產生第二份結果。
- 里程碑：M1
- 優先：必要

#### AC-OR-04 完成單次推進任務
- Given `single_impulse_mission` 與其合格推進
- When 預覽後確認推進並飛行
- Then 在 `expected_success` 的時間容差內進入目標，速度符合限制，標記成功且保留正確剩餘燃料；結果可連回該筆推進
- 驗證：自動

#### AC-OR-05 無推進、撞擊與越界結果
- Given `terminal_baselines` 的各獨立失敗案例
- When 執行至終止
- Then 依資料顯示逾時、撞擊或越界及事件時間，不把缺少合格推進的接近判為成功，結束後狀態不再變動
- 驗證：自動

### REQ-OR-04 固定雙中心的受限飛越

M2 加入資料列出的固定重力來源並加總其作用，允許探測器飛越次要來源附近。來源位置不互相改變；畫面須明示此模型界線，不能稱為真實行星重力助推。
- 里程碑：M2
- 優先：必要

#### AC-OR-06 小型飛越數值參考
- Given `restricted_flyby` 的來源、初始條件與取樣時間
- When 無推進地執行至指定終點
- Then 各取樣位置、速度與最近接近距離符合 `tolerances.flyby`，來源位置不變，最終能量符合容差；結果標明受限固定雙中心模型
- 驗證：自動

### REQ-OR-05 高速連續事件與最早結果

M3 對整段飛行路徑判定目標與撞擊，不能只看顯示取樣端點。案例中的 `collision_disk` 是重力參數為零的固定來源（`high_speed_events.common.collision_disk_meaning`）。封閉區域邊界含擦邊；初始落在區域內與同時事件依 `event_policy`。相同事件重播或重送只保留一個終止結果。
- 里程碑：M3
- 優先：必要

#### AC-OR-07 端點皆在外的目標穿越
- Given `high_speed_events.target_crossing`，顯示取樣間隔大於穿越區域的時間
- When 執行至下一個顯示取樣時間
- Then 在解析進入時間的容差內記錄成功並停在事件位置，不因兩端點皆在外而漏判；各播放速度結果一致
- 驗證：自動

#### AC-OR-08 跨過碰撞體與先撞後達標
- Given `high_speed_events.collision_crossing` 與 `collision_before_target`
- When 以各指定播放速度執行
- Then 在資料指定的最早撞擊時間失敗，不能穿過碰撞體，也不能在已撞擊後回報目標成功
- 驗證：自動

#### AC-OR-09 邊界、初始與同時事件
- Given `high_speed_events.boundary_cases` 的擦邊、初始在內及同時撞擊與達標案例
- When 執行並重播同一案例
- Then 事件時間、優先順序與結果符合資料，每次執行只有一個終止事件，燃料不因重播或重送再被扣除
- 驗證：自動
