# 品質、相容與合規

參考機型：搭載整合顯示晶片的筆電（例如 Apple M1 或 Intel Iris Xe 等級），1920×1080，Chrome 最新版。

### REQ-QA-01 流暢
交戰動畫與鏡頭移動不卡頓。
- 里程碑：M1
- 優先：必要

#### AC-QA-01 幀率
- Given 參考機型，6 格全滿的交戰
- When 以瀏覽器效能工具錄製整段交戰
- Then 幀率中位數 ≥ 50 fps，最長單幀 ≤ 100 ms；回報附機型、瀏覽器版本與錄製檔
- 驗證：手動

### REQ-QA-02 載入快
打開網址很快就能操作。
- 里程碑：M1
- 優先：必要

#### AC-QA-02 下載量
- Given 正式建置輸出
- When 計算首次進入主選單所需下載的檔案總量（壓縮後）
- Then ≤ 15 MB
- 驗證：自動

#### AC-QA-03 可操作時間
- Given 參考機型、清空快取、網路節流 20 Mbps
- When 開啟網址
- Then 5 秒內主選單可點擊
- 驗證：手動

### REQ-QA-03 瀏覽器相容
桌機主流瀏覽器都能玩；不支援時給明確說明。
- 里程碑：M1
- 優先：必要

#### AC-QA-04 支援的瀏覽器
- Given Chrome、Edge、Firefox、Safari 各自最新的兩個主版本（桌機）
- When 各打一局到結束
- Then 都能完成，沒有畫面破損或錯誤訊息
- 驗證：手動

#### AC-QA-05 不支援 WebGL2
- Given 停用 WebGL2 的瀏覽器
- When 開啟網址
- Then 顯示繁體中文說明頁，指出原因與支援的瀏覽器，不出現空白頁
- 驗證：自動

### REQ-QA-04 純靜態部署
符合限制 C-02：建置結果是一組靜態檔案，放在網站子路徑下也能運作。
- 里程碑：M1
- 優先：必要

#### AC-QA-06 子路徑部署
- Given 建置輸出放在靜態伺服器的 `/sanguo-cards/` 子路徑
- When 開啟該網址並打完一局
- Then 所有資源載入成功（無 404），全程沒有對外部 API 或後端的請求
- 驗證：自動

### REQ-QA-05 一局時長
一局 8–15 分鐘，符合「空檔玩一局」的定位。
- 里程碑：M1
- 優先：應有

#### AC-QA-07 試玩時長
- Given 5 位（或 owner 本人 5 局）熟悉規則的玩家以正常動畫速度對電腦
- When 記錄每局時長
- Then 中位數在 8–15 分鐘；超出時回報實測值並提出規則或數值調整的 SDD PR
- 驗證：人工確認

### REQ-QA-06 不只靠顏色
兵種、陣營、敵我不能只靠顏色區分，色覺辨識困難的玩家也能玩。
- 里程碑：M1
- 優先：必要

#### AC-QA-08 灰階可辨
- Given 對局畫面轉成灰階
- When 檢視場上部隊與手牌
- Then 仍能分辨兵種（圖示加文字）、陣營（標記）與敵我（位置與標記）
- 驗證：手動

### REQ-QA-07 鍵盤操作
M2 起不用滑鼠也能完成一局。
- 里程碑：M2
- 優先：應有

#### AC-QA-09 全鍵盤一局
- Given 不使用滑鼠
- When 只用鍵盤開始對戰、選卡、選格位、選目標、使用主公技、結束回合、投降
- Then 都能完成，焦點位置始終可見
- 驗證：手動

### REQ-QA-08 素材與名稱合規
符合限制 C-03，公開發佈前要能說清楚每項素材的來源。
- 里程碑：M1
- 優先：必要

#### AC-QA-10 出處清單
- Given M1 版本
- When owner 檢視遊戲內「素材出處」與專案的素材清單
- Then 每項非自製素材都有來源與授權；介面與卡面沒有出現限制 C-03 列出的作品名稱、美術或規則文案
- 驗證：人工確認
