# 對局規則

本檔先給規則全文（§A），再列可驗收的需求（§B）。規則用到的卡片數值以 [data/cards.yaml](../data/cards.yaml) 為準；AC 中的「測試部隊」是只為描述案例而設的假想卡，不在卡池裡。

## A. 規則全文

### 名詞

| 名詞 | 定義 |
| --- | --- |
| 主公 | 每方一名，不佔格位。有城防（初始 30）與一個主公技。城防歸零即敗。 |
| 糧 | 出牌與主公技的資源。有「目前」與「上限」兩個值，上限最高 10。 |
| 部隊 | 放上沙盤的卡，有費用、攻、兵力、兵種。武將是有名字與技能的部隊，牌組中同名最多 1 張。 |
| 計策 | 打出後立即結算、然後進棄牌堆的卡。 |
| 兵種 | 步、騎、弓、謀。弓與謀是遠程，步與騎是近戰。 |
| 路、格位 | 戰場分左翼、中軍、右翼三路。每路每方有前排、後排各一格，共 12 格。 |

### 對局準備

1. 雙方各選一副合法牌組（30 張）並洗牌。先後手由種子決定。
2. 先手抽 4 張；後手抽 5 張，另得 1 張「軍糧」（0 費計策：本回合目前糧 +1，可超過上限）。
3. 雙方主公城防 30，糧上限 0。

### 回合流程（輪到的一方稱「行動方」）

1. **準備**：糧上限 +1（最多 10），目前糧補滿到上限。任一路己方前排空、後排有近戰部隊時，該部隊移到前排。然後抽 1 張。
2. **主要**：任意順序、任意次數地出牌；主公技每回合最多用 1 次。行動方可隨時宣告結束主要階段。
3. **交戰**：依下方交戰規則，行動方的部隊攻擊。對方部隊不主動攻擊。
4. **結束**：「本回合」效果失效，換對方回合。

### 出牌

- 費用從目前糧扣除，糧不足不能出。
- 部隊放進己方任一空格位；沒有空格位就不能出部隊。前排、後排都可以放。
- 本回合登場的部隊不參與本回合交戰，除非有「衝鋒」。
- 需要目標的卡，沒有合法目標就不能出。

### 交戰

1. **順序**：左翼 → 中軍 → 右翼；每路先前排、再後排。
2. **誰參與**：前排的所有部隊；後排只有遠程部隊（弓、謀）。本回合登場且沒有衝鋒的部隊不參與。
3. **目標**：同路敵方前排 → 若空，同路敵方後排 → 若也空，敵方主公。有「突襲」時改為先後排、再前排、再主公。每次攻擊當下重新判定目標。
4. **傷害**：攻擊者對目標造成等於其攻的傷害。
5. **兵種相剋**：騎剋弓、弓剋步、步剋騎。造成傷害的一方剋對方時，該次傷害 +1。謀不剋也不被剋。對主公不計相剋。
6. **反擊**：近戰部隊攻擊近戰部隊時，目標同時對攻擊者造成等於目標攻的傷害（同樣計相剋）。遠程攻擊、攻擊遠程部隊、攻擊主公都沒有反擊。
7. **陣亡**：每次攻擊（含反擊）結算後，兵力 ≤ 0 的部隊同時陣亡、進棄牌堆，再依交戰順序結算「陣亡」效果。
8. 主公城防 ≤ 0 時立即判定勝負，不再繼續交戰。

### 關鍵字

| 關鍵字 | 效果 |
| --- | --- |
| 衝鋒 | 登場當回合可參與交戰。 |
| 堅守 N | 每次受到的傷害減 N，最低 0。 |
| 突襲 | 交戰目標順序改為後排 → 前排 → 主公。 |
| 連擊 | 每次交戰攻擊兩次，第二次重新判定目標。每次都可能被反擊。 |
| 登場 | 從手牌打出、放上格位後結算一次。 |
| 陣亡 | 該部隊陣亡時結算一次。 |

### 抽牌與手牌

- 手牌上限 10。手牌已滿時抽到的牌直接進棄牌堆。
- 牌組空了仍要抽牌時，改為主公受到疲勞傷害：同一方第 1 次 1 點、第 2 次 2 點，依此遞增。

### 勝負

- 一方主公城防 ≤ 0 即敗；雙方同時 ≤ 0 為平局。
- 第 50 回合（雙方各 25 回合）結束時尚未分出勝負：城防高者勝，相同為平局。
- 任何時候可投降，投降方敗。

## B. 需求

### REQ-RUL-01 對局準備
雙方以合法牌組開局，後手以額外手牌與軍糧補償先手優勢。
- 里程碑：M1
- 優先：必要

#### AC-RUL-01 起手牌與軍糧
- Given 兩副合法牌組與固定種子
- When 對局開始
- Then 先手手牌 4 張；後手手牌 5 張加 1 張軍糧；雙方牌組剩 26、25 張；雙方城防 30、糧上限 0
- 驗證：自動

#### AC-RUL-02 先後手由種子決定
- Given 同一對牌組
- When 以種子 s 開局兩次
- Then 兩次先手相同；以 1000 個不同種子開局時，兩方先手次數各在 450–550 之間
- 驗證：自動

### REQ-RUL-02 糧
糧是唯一資源，逐回合成長，讓對局有前中後期。
- 里程碑：M1
- 優先：必要

#### AC-RUL-03 糧成長與上限
- Given 一方糧上限 9、目前 0
- When 連續進入該方第 2 個與第 3 個準備階段
- Then 上限依序為 10、10，目前糧每次補滿到 10
- 驗證：自動

#### AC-RUL-04 軍糧可超過上限
- Given 後手糧上限 1、目前 1，手上有軍糧
- When 打出軍糧
- Then 目前糧為 2；回合結束後下個準備階段目前糧回到新上限
- 驗證：自動

### REQ-RUL-03 回合流程
回合分準備、主要、交戰、結束四階段，順序固定。
- 里程碑：M1
- 優先：必要

#### AC-RUL-05 後排近戰部隊前移
- Given 行動方左翼前排空、後排有一個近戰測試部隊；中軍前排空、後排有一個弓兵
- When 進入行動方準備階段
- Then 左翼的近戰部隊移到前排；中軍的弓兵留在後排
- 驗證：自動

#### AC-RUL-06 本回合效果在結束階段失效
- Given 行動方對一路部隊使用「鼓舞士氣」（本回合攻 +2）
- When 該回合結束、進入對方回合
- Then 那些部隊的攻回到原值
- 驗證：自動

### REQ-RUL-04 出牌與格位
出牌受糧與格位限制；新部隊預設要等一回合才參戰。
- 里程碑：M1
- 優先：必要

#### AC-RUL-07 糧不足或無空格不能出
- Given 行動方目前糧 2、手上有 3 費部隊；另一情境中己方 6 格全滿、手上有 1 費部隊
- When 嘗試出這兩張牌
- Then 兩次都被拒絕；手牌、糧、場面都不變
- 驗證：自動

#### AC-RUL-08 新登場部隊不參戰
- Given 行動方本回合在中軍前排放一個無衝鋒的 2/3 測試部隊，敵方中軍無部隊
- When 進入交戰
- Then 敵方主公城防不變
- 驗證：自動

### REQ-RUL-05 交戰順序與目標
交戰完全由規則決定，玩家看得懂、測試算得出。
- 里程碑：M1
- 優先：必要

#### AC-RUL-09 目標順序
- Given 行動方中軍前排有一個 3/5 步兵測試部隊（已可參戰）；敵方中軍前排空、後排有一個 1/1 弓兵
- When 進入交戰
- Then 步兵攻擊敵方後排弓兵；弓兵陣亡；敵方主公城防不變
- 驗證：自動

#### AC-RUL-10 空路直擊主公
- Given 行動方右翼前排有一個攻 4 的可參戰部隊，敵方右翼兩格都空
- When 進入交戰
- Then 敵方主公城防減 4
- 驗證：自動

#### AC-RUL-11 交戰順序
- Given 行動方三路前排都有可參戰部隊，各自目標都是敵方主公，攻分別為 1、2、3（左、中、右）
- When 進入交戰並記錄事件序列
- Then 主公受傷事件依序為 1、2、3
- 驗證：自動

### REQ-RUL-06 傷害、反擊與兵種相剋
近戰互換傷害，遠程不吃反擊；相剋固定 +1。
- 里程碑：M1
- 優先：必要

#### AC-RUL-12 近戰反擊
- Given 行動方 3/4 步兵攻擊敵方 2/3 步兵
- When 結算這次攻擊
- Then 敵方步兵兵力 0 陣亡；行動方步兵兵力 2
- 驗證：自動

#### AC-RUL-13 相剋加成與遠程無反擊
- Given 行動方後排 2/3 弓兵（可參戰）攻擊敵方前排 2/5 步兵
- When 結算這次攻擊
- Then 敵方步兵兵力 2（受 3 點）；行動方弓兵兵力 3 不變
- 驗證：自動

#### AC-RUL-14 反擊也計相剋
- Given 行動方 2/5 騎兵攻擊敵方 1/4 步兵
- When 結算這次攻擊
- Then 敵方步兵兵力 2；行動方騎兵兵力 3（受 1+1 點）
- 驗證：自動

### REQ-RUL-07 關鍵字
關鍵字效果與規則全文一致，所有卡片共用同一套定義。
- 里程碑：M1
- 優先：必要

#### AC-RUL-15 衝鋒
- Given 行動方本回合在左翼前排放「輕騎」（2/1 衝鋒），敵方左翼空
- When 進入交戰
- Then 敵方主公城防減 2
- 驗證：自動

#### AC-RUL-16 堅守
- Given 敵方前排「盾兵」（1/5 堅守1）
- When 被行動方 3/3 騎兵攻擊
- Then 盾兵兵力 3（受 3−1 點）；騎兵兵力 1（盾兵反擊 1，步剋騎 +1）
- 驗證：自動

#### AC-RUL-17 突襲與連擊
- Given 行動方「趙雲」（3/4 突襲）攻擊的路上，敵方前排 2/3 步兵、後排 1/1 弓兵；另一情境中「黃忠」（3/3 連擊）在後排，敵方同路前排 1/2 步兵、後排空
- When 各自結算交戰
- Then 趙雲攻擊後排弓兵；黃忠第一次攻擊消滅步兵（3+1 點），第二次攻擊敵方主公 3 點
- 驗證：自動

#### AC-RUL-18 登場與陣亡效果
- Given 「郭嘉」（陣亡：抽 2 張）在場、其牌組至少 2 張
- When 郭嘉在交戰中陣亡
- Then 郭嘉一方手牌增加 2 張（未超過上限時）
- 驗證：自動

### REQ-RUL-08 主公技
每個主公有一個每回合可用一次的主公技，費用 2 糧，讓糧有固定出口。
- 里程碑：M1
- 優先：必要

#### AC-RUL-19 每回合一次
- Given 行動方目前糧 6
- When 使用主公技兩次
- Then 第一次成功、目前糧 4；第二次被拒絕、糧不變
- 驗證：自動

### REQ-RUL-09 抽牌、手牌上限與疲勞
防止無限拖延，牌用完會受懲罰。
- 里程碑：M1
- 優先：必要

#### AC-RUL-20 手牌上限
- Given 行動方手牌 10 張、牌組 5 張
- When 準備階段抽牌
- Then 手牌仍 10 張；牌組 4 張；抽到的牌在棄牌堆
- 驗證：自動

#### AC-RUL-21 疲勞遞增
- Given 一方牌組 0 張
- When 該方連續三個準備階段
- Then 其主公依序受到 1、2、3 點傷害
- 驗證：自動

### REQ-RUL-10 勝負
勝負條件簡單明確，對局一定會結束。
- 里程碑：M1
- 優先：必要

#### AC-RUL-22 城防歸零立即結束
- Given 敵方城防 3，行動方左翼與中軍各有一個可直擊主公的攻 3 部隊
- When 進入交戰
- Then 左翼攻擊後對局結束、行動方勝；中軍部隊沒有攻擊事件
- 驗證：自動

#### AC-RUL-23 回合上限
- Given 第 50 回合結束時雙方城防 12 與 9
- When 結束階段完成
- Then 城防 12 的一方勝；城防相同時為平局
- 驗證：自動

#### AC-RUL-24 投降
- Given 對局進行中
- When 一方投降
- Then 對局結束，投降方敗，結果原因為「投降」
- 驗證：自動

### REQ-RUL-11 對局可重現
同一種子加同一操作序列一定得到同一結果，方便測試、評估電腦對手與回報錯誤（限制 C-05）。
- 里程碑：M1
- 優先：必要

#### AC-RUL-25 重播一致
- Given 一局完整對局的種子與操作序列
- When 重播 100 次
- Then 每次的事件序列與最終結果完全相同
- 驗證：自動

### REQ-RUL-12 拒絕不合法操作
規則引擎是唯一裁判；介面或電腦對手送出的不合法操作一律拒絕且不改變狀態。
- 里程碑：M1
- 優先：必要

#### AC-RUL-26 非行動方操作
- Given 輪到 A 方
- When B 方送出出牌或主公技操作
- Then 操作被拒絕，對局狀態完全不變，並回傳原因
- 驗證：自動
