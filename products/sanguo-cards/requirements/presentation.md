# 3D 呈現與操作

依限制 C-01 使用 three.js。本檔只寫玩家看到與操作到的結果；場景結構、模型格式、著色方式由項目決定。

### REQ-PRE-01 沙盤戰場
戰場是一張俯視、略帶傾斜的 3D 沙盤，三路與前後排一眼看得出來。
- 里程碑：M1
- 優先：必要

#### AC-PRE-01 一屏看完
- Given 瀏覽器視窗 1280×720 與 1920×1080
- When 進入對局
- Then 不捲動、不調整鏡頭就能同時看到 12 個格位、三路名稱、雙方主公城防、己方手牌與糧
- 驗證：手動

#### AC-PRE-02 視窗縮放
- Given 對局進行中
- When 視窗在 1280×720 與 1920×1080 之間調整大小
- Then 畫面在 1 秒內重新排版，不變形、不出現裁切的格位或文字
- 驗證：手動

### REQ-PRE-02 出牌操作
拖放與點選兩種方式都能出牌，滑鼠新手與觸控板使用者都順手。
- 里程碑：M1
- 優先：必要

#### AC-PRE-03 拖放與點選
- Given 行動方手上有一張可出的部隊卡
- When 分別用「拖到格位放開」與「先點卡、再點格位」兩種方式出牌
- Then 兩種方式都成功放上指定格位；選取卡片時合法格位有高亮，不合法的沒有
- 驗證：手動

#### AC-PRE-04 不合法放置會退回
- Given 行動方拖著一張部隊卡
- When 放到已有部隊的格位或敵方格位
- Then 卡片回到手牌，糧不變，沒有錯誤畫面
- 驗證：手動

#### AC-PRE-05 選目標與取消
- Given 行動方打出需要目標的計策（例如「落石」）
- When 進入選目標狀態後按 Esc 或滑鼠右鍵
- Then 只有合法目標高亮；取消後卡片回到手牌，糧不變
- 驗證：手動

### REQ-PRE-03 交戰動畫
交戰是這款遊戲的觀賞時刻，要看得懂誰打誰、打了多少，但不能拖節奏。
- 里程碑：M1
- 優先：必要

#### AC-PRE-06 依規則順序呈現
- Given 一次有 4 次攻擊（含一次反擊與一次陣亡）的交戰
- When 以正常速度觀看
- Then 攻擊依規則順序逐一演出；每次傷害有飄字數值；相剋傷害有額外標示；陣亡部隊有退場動畫後才消失
- 驗證：手動

#### AC-PRE-07 交戰時長上限與略過
- Given 一次 6 格全參戰的交戰
- When 以正常速度觀看；另一次按「略過」
- Then 正常速度整段 ≤ 6 秒；略過時 0.5 秒內直接顯示結算後的場面，結果與不略過相同
- 驗證：手動

### REQ-PRE-04 資訊可讀
任何時候都能看清場面與卡片細節，不靠記憶。
- 里程碑：M1
- 優先：必要

#### AC-PRE-08 放大檢視與關鍵字說明
- Given 手牌或場上任一張卡
- When 滑鼠停留 0.3 秒
- Then 顯示放大卡面與每個關鍵字的一句話說明；移開即消失
- 驗證：手動

#### AC-PRE-09 狀態列
- Given 對局進行中
- When 任意時刻截圖
- Then 截圖中可讀出：目前行動方、回合數與上限、雙方城防、己方糧（目前／上限）、雙方牌組張數、對手手牌張數；場上部隊的攻與兵力常駐顯示，被增減的數值以顏色加箭頭標示
- 驗證：手動

### REQ-PRE-05 對局紀錄
側邊有文字紀錄，事後能回看發生了什麼，也幫助不方便看動畫的玩家。
- 里程碑：M1
- 優先：必要

#### AC-PRE-10 每個事件都有紀錄
- Given 一局完整對局
- When 對照規則引擎的事件序列與畫面上的紀錄
- Then 每次出牌、主公技、攻擊、傷害、陣亡、抽牌（對手只記張數）都有一筆繁體中文紀錄，順序一致
- 驗證：自動

### REQ-PRE-06 勝負畫面
對局結束要清楚交代結果與原因，並能馬上再來一局。
- 里程碑：M1
- 優先：必要

#### AC-PRE-11 結果與再戰
- Given 對局以城防歸零、回合上限或投降任一種方式結束
- When 顯示結束畫面
- Then 畫面寫出勝方與原因，提供「再來一局（同陣營）」「換陣營」「回主選單」三個選項，各自可用
- 驗證：手動

### REQ-PRE-07 動畫速度與減少動態
玩家可以調快動畫；對動態敏感的玩家可以關掉鏡頭晃動等效果。
- 里程碑：M1
- 優先：應有

#### AC-PRE-12 動畫速度
- Given 設定中動畫速度可選 0.5×、1×、2×
- When 選 2× 後觀看 AC-PRE-07 的交戰
- Then 整段時長約為 1× 的一半（±20%）
- 驗證：手動

#### AC-PRE-13 減少動態
- Given 開啟「減少動態」
- When 觀看一整個回合
- Then 沒有鏡頭晃動、閃光與大幅位移；資訊與事件順序與關閉時相同
- 驗證：手動

### REQ-PRE-08 正式美術與音效
M2 換上正式美術與音效，風格統一，符合限制 C-03。
- 里程碑：M2
- 優先：必要

#### AC-PRE-14 美術風格與出處
- Given M2 版本
- When owner 檢視主選單、對局、結束畫面與 10 張以上卡面
- Then owner 確認風格一致、可辨識三路與兵種；遊戲內「素材出處」頁列出每項外部素材的來源與授權，沒有限制 C-03 禁止的內容
- 驗證：人工確認

#### AC-PRE-15 音效可關閉
- Given M2 版本，首次開啟遊戲
- When 進入主選單
- Then 音樂與音效預設音量不超過 50%，設定中可分別調整與靜音，重新整理後保留
- 驗證：手動
