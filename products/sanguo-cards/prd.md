# PRD：群雄・三國卡牌（暫名）

## 1. 一句話

在瀏覽器裡打開就能玩的三國題材卡牌對戰：雙方主公在一張 3D 沙盤上分三路布陣，武將與兵種卡自動交戰，十分鐘左右分出勝負。

## 2. 對象與情境

| 對象 | 情境 | 他要什麼 |
| --- | --- | --- |
| 三國愛好者、輕度策略玩家 | 午休或通勤空檔，桌機或筆電 | 打開網址就能玩，一局 8–15 分鐘，不用註冊 |
| 卡牌遊戲老手 | 想試新規則 | 規則有深度但一頁說得完；三路布陣帶出取捨 |
| owner 本人 | 驗證 three.js 與 agent 協作開發流程 | 規則可自動測試、可重現，適合 agent 長期迭代 |

## 3. 核心體驗

1. **沙盤布陣。** 戰場是一張俯視的 3D 沙盤，分左翼、中軍、右翼三路；每路每方有前排、後排各一格。出牌就是把部隊放上沙盤。
2. **自動交戰。** 回合結束前進入交戰，己方部隊依固定順序攻擊同路敵軍；某路沒有敵軍時直接打到敵方主公。玩家的決策集中在「放哪一路、放前排或後排、什麼時候用計策」。
3. **兵種相剋。** 騎兵剋弓兵、弓兵剋步兵、步兵剋騎兵，相剋時多 1 點傷害。看一眼就懂，又會影響每一路的取捨。
4. **武將有個性。** 武將卡是唯一的，技能取材於史實或演義（關羽衝鋒、張遼突襲、郭嘉遺計），讓人一眼認出是誰。
5. **陣營手感不同。** 蜀重武將與回復，魏重控制與資源，吳重火攻與水戰，群雄重爆發與代價。

規則全文見 [requirements/rules.md](requirements/rules.md)，卡池見 [data/cards.yaml](data/cards.yaml)。

## 4. 範圍

| 里程碑 | 一句話 |
| --- | --- |
| M1 可玩切片 | 蜀 vs 魏，固定牌組，人對電腦，完整一局規則與 3D 沙盤 |

細節見 [milestones.md](milestones.md)。

## 5. 非目標

- 線上對戰、帳號、伺服器、排行榜。
- 抽卡、付費、廣告、任何真錢交易。
- 手機原生 App。M1、M2 只保證桌機瀏覽器；平板與手機橫向列為 M3 之後再議。
- 隱藏身分的派對玩法（與既有作品區隔，見限制 C-03）。

## 6. 限制

| 編號 | 限制 | 理由 |
| --- | --- | --- |
| C-01 | 3D 呈現使用 three.js | owner 指定，用來驗證 three.js 開發流程 |
| C-02 | 純靜態網站，無後端；可部署在 GitHub Pages 一類的靜態主機 | 零維運成本 |
| C-03 | 不使用 KOEI《三國志》系列、《三國殺》或其他既有作品的名稱、美術、規則文案與 UI。人物與事件取材於史書與《三國演義》，美術與文字自行創作或使用授權明確的素材 | 公開專案，避免侵權與混淆 |
| C-04 | 介面文字以繁體中文為主 | 主要對象 |
| C-05 | 規則結果可用亂數種子重現 | 自動測試、電腦對手評估、回報錯誤都需要可重現的對局 |

## 7. 成功指標

| 指標 | 目標 | 對應 |
| --- | --- | --- |
| 一局時長（人對電腦，中位數） | 8–15 分鐘 | REQ-QA-05 |
