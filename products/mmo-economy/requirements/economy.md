# 經濟規則

所有數值與排序依 [scenarios.yaml](../data/scenarios.yaml)。

### REQ-ECO-01 生產與製造

採集者只產出職業指定原料；製造者一次只執行一項工作，開始時完整扣除配方投入，完成時完整增加產出。採集與製造都算工作：產出與每完成工作的修理費在完成小時結算，受相同的每日工作上限限制。缺料、忙碌或尚未獲得工作時不預先產生商品。暫停後續跑的製造不得重複扣料或重複產出。每日階段的執行時刻與同一小時內的先後依 `behavior.daily_schedule`。
- 里程碑：M1
- 優先：必要

#### AC-ECO-01 配方跨越時間邊界
- Given `production_case` 的原料、配方與時刻
- When 工作開始、在完成前觀察、再推進到完成時刻
- Then 原料與在製工作符合該案例各階段的預期；完成前沒有製成品，完成後只有一次指定產出
- 驗證：自動

#### AC-ECO-02 缺料與忙碌
- Given 同一生產案例，但原料少於需求，或既有工作尚未完成
- When 再請求開始該配方工作
- Then 請求被拒絕並說明缺料或忙碌，資金、庫存及既有完成時間不變
- 驗證：自動

### REQ-ECO-02 買斷市場與定價

賣方上架自己可用庫存，商品轉為託管；買方依需求、可用現金與價格上限選擇最低價賣單，同價依上架時刻及賣單編號排序。成交的商品轉移、扣款、收入及手續費必須一起成功或一起不發生。定價依資料中的每日調整規則，不能直接設定預期價格曲線。
- 里程碑：M1
- 優先：必要

#### AC-ECO-03 一筆成交可對帳
- Given `trade_case` 的買方、賣方、託管數量、單價與手續費規則
- When 買方購買指定數量
- Then 買賣雙方的金錢、庫存、託管與手續費銷毀逐項符合 `expected_after_trade`，且只產生一筆成功成交
- 驗證：自動

#### AC-ECO-04 超額購買與重複執行
- Given 同一賣單的庫存已被前一筆成交用完，或買方現金不足
- When 另一筆購買或同一購買的重複請求到達
- Then 不再扣款、不再轉移物品、不再收費；重複請求顯示原結果，無庫存或資金不足顯示具體拒絕原因
- 驗證：自動

### REQ-ECO-03 貨幣來源與回收

總貨幣等於初始資金加明示任務獎勵、減明示修理與成交費用。市場託管在資產盤點內；本版費用被銷毀而非轉入國庫。每次發行或銷毀都有唯一業務事件及原因；暫停、回看、重複請求不重複結算。
- 里程碑：M1
- 優先：必要

#### AC-ECO-05 交易加發行加回收
- Given `trade_case` 成交後的世界
- When 依 `money_case` 發給買方任務獎勵並扣除修理費
- Then 買方、賣方及全世界現金符合 `money_case.expected`，總額差等於已記錄的發行減銷毀
- 驗證：自動

### REQ-ECO-04 合成玩家的可解釋決策

基準模式依 `population` 分配職業與初始財產，按 `behavior` 的日程與順位行動。製造者依當時價格估算扣除交易費及修理費後的收益，在可買齊原料且可負擔的候選中選擇收益最高者，同分依配方編號；沒有正收益候選就等待。冒險者按需求順位購買，沒有物品或現金就記錄未滿足需求。決策記錄引用當時可見資訊，不能使用未來成交。

公開閉環算例另有排定決策模式，僅由資料預先指定角色要做的合法動作，以核對跨階段執行；它不執行未列出的自主動作，也不聲稱測到了自主策略。生產時間、每日工作上限、價格範圍、交易與帳務規則仍相同，不得直接賦值終點狀態。自主策略另由本需求的決策案例及基準規模驗證。
- 里程碑：M1
- 優先：必要

#### AC-ECO-06 選擇與價格調整有依據
- Given `decision_case` 的候選配方、當時報價、可用原料及前日成交情況
- When 執行當日決策與定價
- Then 選擇及報價符合案例預期；移除全部正收益候選後等待，沒有新增工作或憑空資金
- 驗證：自動

### REQ-ECO-05 草藥腐敗

M3 啟用 `perishability` 後，指定商品依產生時刻到期；產生時刻與同種商品的先後使用順序依 `perishability.born_at`、`lot_order`。到期移除可用與託管庫存，記為腐敗消耗；不扣買方款或收成交費。同時刻先處理到期，再處理購買與新工作；先前已消耗的製造投入不受追溯影響。
- 里程碑：M3
- 優先：必要

#### AC-ECO-07 掛單到期與購買同時發生
- Given `expiry_case` 的草藥掛單、買方資金與到期時刻
- When 購買恰好於草藥到期時刻發生
- Then 草藥與掛單可售量歸零，買賣雙方資金不變，只有腐敗紀錄，沒有成交與成交費
- 驗證：自動

#### AC-ECO-08 腐敗關閉與已投入工作
- Given 一份關閉腐敗的舊基準情境，以及 `expiry_case` 中到期前已開始的製造
- When 重新執行舊基準並讓該製造跨越原料到期時刻完成
- Then 舊基準的 `regression_digest` 與加入腐敗前留存的結果逐項相同；已投入的工作正常產出且沒有第二次原料腐敗扣帳
- 驗證：自動
