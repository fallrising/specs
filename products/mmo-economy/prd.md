# PRD：MMO 經濟危機實驗室

## 1. 一句話

在虛構 MMO 的生產、交易與消耗循環中做可比較的政策實驗，並把任何圖表異常追到具體經濟事件。

## 2. 對象與情境

| 對象 | 情境 | 所需結果 |
| --- | --- | --- |
| 系統設計者 | 評估掉落、配方、金幣來源與回收 | 能調整規則、重跑並查明差異 |
| 模型評測者 | 比較模型能否完成多個互相制約的功能 | 有獨立帳務與庫存判定依據 |
| 玩家或學習者 | 理解市場如何受行為影響 | 能從成交、成本與庫存閱讀結果 |

## 3. 核心體驗

選擇一份公開情境，啟動合成玩家；觀看採集、製造、上架、購買、消耗的連續過程。使用者可暫停查詢一筆成交，回看其買方、賣方、物品、手續費與餘額，再從既有狀態分支，修改一項規則比較後續結果。

價格由參與者可見資訊與明訂行為形成，圖表從實際紀錄計算。模型世界中的結果只代表該組假設，不宣稱能預測真實 MMO 或真實金融市場。

## 4. 範圍

規模與所有數值見 [data/scenarios.yaml](data/scenarios.yaml)。首版包含三條製造鏈、採集者、製造者與冒險者，以及買斷式拍賣市場。

| 里程碑 | 使用者可完成的事 |
| --- | --- |
| M1 經濟閉環 | 從生產到消耗跑完公開案例，逐筆查帳並查看市場概況 |
| M2 實驗可靠性 | 在基準規模跑完整期間，保存／恢復、重播、分支比較與檢查輸入 |
| M3 腐敗變更 | 草藥到期影響庫存與交易，原有非腐敗情境仍保持正確 |

## 5. 非目標

- 還原特定版本《魔獸世界》的全部物品、玩家或拍賣規則。
- 真人帳號、付費交易、外部市場資料串接或線上多人遊戲。
- 為每名合成玩家呼叫線上 LLM。
- 真實經濟預測、金融建議、無限商品數或無限模擬期間。
- 首版完整 3D 世界；觀察介面可以先用圖表與流程視圖。

## 6. 限制

- 使用虛構物品與合成行為，介面繁體中文；資料可本地匯出。
- 使用者不需登入第三方服務即可完成首版流程，執行期不需要付費 API。
- 貨幣以最小整數單位記帳，價格、稅額、庫存與配方遵守業務資料中的範圍與捨入方式。
- 單一情境內，所有參與者遵守相同公開規則，不因評測模型名稱更改難度。
- SimPy／Mesa 僅為前期可行性背景；具體技術選擇留給實作 repo，不是本次 owner 指定義務。

## 7. 成功指標

| 指標 | 判定 |
| --- | --- |
| 完整流程 | 公開生產與交易案例可從開始到結束；每一步有對應的世界狀態 |
| 帳務一致 | 總貨幣變化等於明示發行減銷毀，商品變化符合生產、轉換與消耗 |
| 可重現 | 相同版本、設定及輸入的關鍵世界狀態與經濟紀錄相同 |
| 可比較 | 分支前相同，分支後的政策差異與結果都可查 |
| 可理解 | 使用者能由圖表定位指定成交與相關經濟紀錄 |
| 有界執行 | 基準規模依事前指定設備與量測條件驗證，門檻見業務資料 |

成功不要求價格必然向某方向移動，也不以產生漂亮曲線判定建模正確。

## 8. 待決問題與批准前條件

正式名稱、美術方向與實作 repo 待選定。正式效能設備尚未指定；data 中的門檻是提案。批准前須以參考案例確認預期結果、完成基準規模試跑，並固定採用的規格 SHA。尚未完成這些步驟時維持 draft。
